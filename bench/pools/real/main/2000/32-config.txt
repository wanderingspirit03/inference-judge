File 2: collect.sh (called by cron each minute, and also by the nightly archive job)

```bash
#!/bin/bash
# kiln collector - Greywater Cement Works
DEST=/data/kiln
LOG=/var/log/kiln_collect.log
GATEWAY=$GATEWAY_HOST
TODAY=`date +%Y-%m-%d`

mkdir $DEST
cd $DEST

echo "starting $TODAY" >> $LOG

# fetch the latest readings
curl http://$GATEWAY/api/readings?unit=kiln1 -o readings_$TODAY.json

if [ $? = 0 ]; then
  python /app/parse.py readings_$TODAY.json > parsed.csv
else
  echo "fetch failed" >> $LOG
fi

# push to the database
curl -XPOST "http://influx.greywater.example.org:8086/api/v2/write?org=plant&bucket=kiln" \
  -H "Authorization: Token $INFLUX_TOKEN" \
  --data-binary @parsed.csv >> $LOG

# nightly cleanup and archive
HOUR=`date +%H`
if [ $HOUR = 02 ]; then
  tar czf /backup/kiln_$TODAY.tar.gz $DEST/*
  rm -rf $DEST/*
  scp /backup/kiln_$TODAY.tar.gz archive@10.20.4.90:/archive/
  find /backup -mtime +30 -exec rm {} \;
fi

# alert if kiln temperature is high
TEMP=`grep kiln_shell_temp parsed.csv | tail -1 | cut -d, -f3`
if [ $TEMP -gt 380 ]; then
  echo "kiln shell temperature $TEMP" | mail -s "KILN ALARM" ops@example.org
fi

echo "done" >> $LOG
```

File 3: .ci/pipeline.yml

```yaml
name: kiln-collector

on:
  push:
    branches: [ "**" ]
  pull_request_target:
    branches: [ main ]

env:
  REGISTRY: registry.greywater.example.org
  REGISTRY_PASSWORD: Gw-registry-2024!

jobs:
  build:
    runs-on: self-hosted
    steps:
      - uses: actions/checkout@main
        with:
          ref: ${{ github.event.pull_request.head.sha }}

      - name: Install
        run: |
          pip install -r requirements.txt
          pip install pytest

      - name: Test
        run: pytest || true

      - name: Build image
        run: docker build -t $REGISTRY/kiln-collector:latest .

      - name: Login and push
        run: |
          echo $REGISTRY_PASSWORD | docker login $REGISTRY -u ci --password-stdin
          docker push $REGISTRY/kiln-collector:latest

  deploy:
    needs: build
    runs-on: self-hosted
    steps:
      - name: Deploy to control room server
        run: |
          ssh -o StrictHostKeyChecking=no deploy@10.20.4.31 \
            "docker pull $REGISTRY/kiln-collector:latest && docker stop kiln; docker rm kiln; docker run -d --name kiln --restart always -p 8086:8086 -v /data:/data $REGISTRY/kiln-collector:latest"
      - name: Notify
        run: curl -X POST -d "deployed" https://chat.example.org/hooks/kiln
```

Some context. The server has 4 GB of memory and a 120 GB disk. Readings are about 30 KB a minute. The kiln shell temperature limit is 380 degrees C and an alarm over that is a real safety matter for the shift supervisor. The nightly job has twice produced empty archives, and last month the disk filled up in a weekend. Our colleagues in IT have asked us to stop publishing anything on port 22.
